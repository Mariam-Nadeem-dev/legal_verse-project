Legal Verse

Project Overview

Legal Verse is a website project created for a real lawyer in Pakistan. Its purpose is to introduce the lawyer's work and help visitors explore legal information and find contact details.

Live Website


Built With

- HTML5
- CSS3
- Git and GitHub
- GitHub Pages

Main Features

- Responsive website layout
- Navigation between website sections
- Legal-themed images with alternative text
- Information about the lawyer and legal resources
- Contact section
- Mobile-friendly styling

Responsive Design

The website uses flexible layouts, responsive images, and CSS media queries to adapt to different screen sizes. I will test it on mobile and desktop widths.

How I Used AI

I used AI to help understand and write HTML and CSS, organize the page, and troubleshoot styling problems. I checked the website in the browser instead of accepting every suggestion without testing.

One issue occurred when I changed the hero background gradient: the background looked more washed out. I noticed the change while checking the website and stopped making further changes to that section.

Testing

I will check that the navigation works, images load, text is readable, and the website does not scroll horizontally on small screens.
